# Gestión Apícola — Frontend GitHub Pages

Sitio estático HTML/CSS/JavaScript. Necesita la API PHP incluida en la carpeta `laragon-api/api` del paquete completo.

La URL de la API puede configurarse desde la propia pantalla de ingreso. No hay datos privados en este repositorio.

## Gestión Ganadera v24.7.0 - Pasturas

- Nueva solapa **Pasturas** en Gestión Ganadera.
- Registro de una siembra asociada a una o varias parcelas.
- Curva forrajera anual con germinación, crecimiento, período ideal, floración y semillación.
- Vida útil configurable (5 años por defecto) y fecha automática de resiembra.
- La misma curva se muestra en la ficha de cada parcela asociada.
- La gestión previa de condición/pastoreo/descanso de cada parcela se conserva sin cambios.

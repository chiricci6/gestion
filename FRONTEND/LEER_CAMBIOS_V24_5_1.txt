GESTIÓN APÍCOLA · CONTABILIDAD
- Todo ingreso/venta nuevo se identifica como originado en Apiario La Ruda.
- El reparto entre Chiara y Felipe se calcula automáticamente según sus saldos históricos.
- Si ambos están negativos: se cubren proporcionalmente según la deuda.
- Si solo uno está negativo: primero se compensa ese saldo.
- Si el ingreso supera las deudas: el excedente se divide 50/50.
- Si ambos están en cero o positivo: 50/50 obligatorio.
- La pantalla muestra el reparto estimado antes de guardar.
- Las ventas registradas desde Apiario La Ruda usan la misma regla para repartir la ganancia, después de recuperar el costo de materiales.

ACTIVIDADES
- Gestión Apícola y Comunidad: la vista de lectura ahora muestra correctamente la etiqueta aunque el endpoint individual no la hubiera enviado antes.
- Gestión Apícola incorpora la etiqueta persistente "Control sanitario".
- Comunidad migra la antigua etiqueta "Comunidad" a "Control sanitario".

IMPORTANTE
Esta actualización requiere FRONTEND + BACKEND. El cálculo contable se valida y guarda en servidor para que sea consistente desde cualquier dispositivo.
